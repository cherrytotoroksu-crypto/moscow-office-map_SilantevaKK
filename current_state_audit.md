### 1.2 Реальная, подтверждённая, АКТИВНАЯ проблема: скачки координат

  прыгнула) — это прямое подтверждение гипотезы "геокодируется не по
  адресу, а по чему-то другому" (см. п.1.3).

### Аренда/Гибкие офисы — по кварталам не пересчитывал полностью в этом заходе

Формула цены аренды/гибких офисов в коде (`codifier.html`,
`computeSegmentKPIs`) — раздельная от продажи, использует `rent_lots_*.json`/
`coworking_*.json`, не смешивается с `lot_total_price` продажи (проверено
структурно: разные файлы, разные единицы — руб/м²/год для аренды,
руб/мес для гибких — не GLA здания). Для Q2 2026 KPI аренды/гибких офисов
тоже уже переключены на Golden File (см. предыдущий коммит). По остальным
16 кварталам bottom-up числа не сверял с контрольным отчётом — Golden File
за другие кварталы не предоставлялся.

### Формула цены продажи

`SUM(lot_total_price) / SUM(lot_area)` — реализовано именно так в
`computeTotals('sale_lots')` и `computeSegmentKPIs` (`saleTotal / saleArea`,
где `saleTotal = Σ lot.total`, `saleArea = Σ lot.area`), не `AVG(price)`.
Regression-тест на это уже есть (`tests/test_sale_lots_kpi_integrity.py`,
`WeightedPriceFormulaTest`).
