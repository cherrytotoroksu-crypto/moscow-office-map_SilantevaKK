# Координация проверки базы московских офисов

Снимок: 2026-07-27, Москва.  
Источник данных: локальный проект `moscow-office-map`.  
Роль Claude Code: владелец правок исходных данных и `classifier.html`.  
Роль Codex: независимый аудит, поиск противоречий и повторная проверка после правок.

## Правила совместной работы

1. Одновременно редактирует исходные JSON/HTML только Claude Code. Codex не меняет файлы проекта во время активной сессии Claude.
2. Каждая находка проходит состояния `OPEN → CLAIMED → FIXED → RECHECKED`. Статус `FIXED` без повторной машинной проверки не считается завершением.
3. Автоматически исправляются только случаи с однозначным соответствием сущности и минимум двумя независимыми подтверждениями либо с одним первичным источником.
4. Если расходятся название, адрес и координаты, запись не «чинится по ближайшей точке»: сначала проверяется, не смешаны ли два разных объекта или не переиспользован ли ID.
5. Массовая замена должна матчиться как минимум по `id + name/name_orig + address` и старому значению. Матч только по названию недостаточно безопасен.
6. После каждого пакета правок обязательны: разбор всех JSON, поиск дублей ID, повторяющейся заглушки координат, скачков координат между кварталами и рассинхронизации `buildings/lots/rent_lots`.

- Статус: `FIXED` (Claude Code, 2026-07-27 — детали в qa_handoff.json)
- Приоритет: критический для идентичности записей
- В Q2 2026 ID 255 повторён 4 раза, ID 257 — 2 раза.
- У строк разные значения `vacancy`, поэтому удалять их как простые дубли нельзя: это могут быть отдельные предложения, ошибочно сведённые в одну сущность.

## Техническая приёмка после правок

- JSON-файлы разбираются без ошибок.
- В актуальном квартале нет координатной заглушки `55.755819, 37.617644`.
- Нет `0,0`, координат вне Москвы/ближней агломерации и необъяснимых скачков одного ID между кварталами.
- В пределах квартала ID уникальны или явно документирована модель «один ID — несколько предложений».
- Название, БЦ, адрес и координаты проверяются как единый набор.
- Производный `classifier.html` не расходится с JSON-источниками.
- Повторный аудит выполняется на чистом снимке после завершения записи файлов.
