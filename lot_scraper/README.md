# Выгрузка лотов с сайтов застройщиков

Локальный инструмент: парсеры по сайтам застройщиков + веб-страница `scraper.html` (внутри сайта офисов).
Только первичная продажа, только официальные сайты застройщиков. Работает **только на этом компьютере**
(сервер слушает 127.0.0.1) и в публичный сайт не попадает: `build_public_site.py` копирует только свои
списки файлов, `scraper.html` и `lot_scraper/` в них нет.

## Как запустить

Двойной клик по `запустить-выгрузку-лотов.bat` в корне проекта (или `python lot_scraper/server.py`).
Откроется `http://localhost:3457/scraper.html`. Ссылка «Выгрузка лотов с сайтов» есть и в `classifier.html`
(показывается только при локальном запуске).

* **Скачать всё** — все корпуса, для которых есть парсер.
* **Скачать выборочно** — слева девелоперы (галочка выбирает все его корпуса), справа список зданий с поиском.
  Корпуса без парсера видны серыми и не выбираются (причина во всплывающей подсказке).
* Результат (кнопки появятся после выгрузки): **таблица в 39 колонок** по памятке `office-lot-workbooks`
  и **сырые данные**. Файлы лежат в `lot_scraper/out/` (в git не попадают).

Без интерфейса: `python lot_scraper/engine.py --all` или `python lot_scraper/engine.py 216|04 279|02`.

## Что в таблице на 39 колонок

* Листы: «Продажа» (39 колонок), «Сопоставление с Q3» (лоты: сопоставлен / цена изменилась / новый / ушёл),
  «Отчёт по корпусам» (сколько лотов, расхождения, ниже — что **не выгружено** и почему),
  «Пометки по лотам», «База для проверки» (фаза и схема из Q3 для сверки).
* Метаданные корпуса (ID, девелопер, класс, адрес, площади, округ/район/зона/субрынок, координаты) — из свода Q3 2026
  (самый свежий `Q3 2026\Свод Q3 2026_итоговый_*.xlsx`; другой путь — в `lot_scraper/config.json`: `{"svod": "C:/.../файл.xlsx"}`).
* **Фаза проекта и Схема продажи пустые** — проверяются отдельно. «Цена без НДС», «₽/м² без НДС» и «НДС»
  считаются формулами от схемы и заполнятся сами, когда схема будет вписана. «Вес» не заполняется.
* Строки без цены или без площади подсвечены красным: в расчёты их брать нельзя.
* Цена — опубликованная на сайте с НДС. Если у лота две цены (скидка за 100% оплату, акция), берётся основная,
  вторая пишется в «Пометки по лотам».

## VPN / сеть

Скрипты ходят в сеть так же, как любая программа на компьютере: включил системный VPN — работают через него.
Если VPN работает через прокси, задай `HTTPS_PROXY` перед запуском (его подхватывают и `requests`, и браузерная отрисовка).
Часть сайтов (Forma, STONE, MR Group, A101, Dominanta и др.) без нужной сети отвечает таймаутом — парсер повторяет попытку
3 раза, потом ещё раз в конце; корпус с ошибкой остаётся в отчёте, а не пропадает молча.

## Как добавить сайт

1. Разведка: `python lot_scraper/pw_xhr.py <url> [селектор]` печатает все XHR страницы — часто есть прямой JSON.
2. Парсер `sites/<имя>.py` с функцией `run(target) -> Result` (образцы: `a101.py` — JSON API, `tsetlin.py` — HTML,
   `coldy.py` — отрисовка в браузере). Лот добавляется через `r.add(...)`, пометки про цену/площадь ставятся сами.
3. Строка в `targets.py`: `add('имя_парсера', project_id, sub_id, проект, корпус, url, ...)`. ID — из свода Q3.
4. Корпус сразу появится в интерфейсе. Заметки по платформам и готовым скриптам — `webscraper_notes.md`.

## Файлы

`engine.py` — запуск и экспорт · `server.py` — локальный сервер и API · `build_39.py` — сборка 39 колонок ·
`make_registry.py` — список корпусов Q3 (`registry_q3.csv`, создаётся сам, в git не хранится) ·
`core.py`, `browser.py` — общее ядро (загрузка с повторами, отрисовка Playwright) · `sites/` — парсеры · `targets.py` — корпуса.

Нужны: `requests`, `beautifulsoup4`, `lxml`, `openpyxl`, `playwright` (+ `python -m playwright install chromium`) — см. `requirements.txt`.
