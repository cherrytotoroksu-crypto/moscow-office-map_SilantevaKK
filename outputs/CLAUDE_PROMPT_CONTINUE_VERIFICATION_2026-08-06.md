## Рабочие ограничения, проверенные на практике

- Все правки — только через `data/future_projects_verification_overrides.json`.
  `data/future_projects.json` генерируется скриптом.
- Python запускать через runtime QGIS:
  `PYTHONHOME="/c/Program Files/QGIS 3.40.8/apps/Python312" PYTHONIOENCODING=utf-8
  "/c/Program Files/QGIS 3.40.8/bin/python3.exe"`. Кириллица в консоли Windows не
  печатается — выводить в файл и читать оттуда.
- `scripts/build_public_site.py` иногда падает с `PermissionError` на
  `_site/data/qa` из-за OneDrive; лечится удалением `_site` через PowerShell и
  повторным запуском. На CI проблемы нет.
- Nominatim по адресам вида «Бумажный проезд, 19с2» отдаёт центр улицы — такую
  координату наносить нельзя. Overpass по номерам строений в этих кварталах пуст.
- `data/building_dates.json` — чужая незавершённая правка, не трогать.
