# Коллизии координат коворкингов по периодам

Проверены все доступные `coworking_*.json` за 2024–2026.

В каждом периоде есть координатные группы, где несколько сетей/площадок имеют одну точку. Это не следует автоматически считать дублем проекта: несколько операторов могут работать в одном БЦ.

Повторяющиеся коллизии:

- 55.755819, 37.617644 — до 9 разных операторов;
- 55.747606, 37.625729 — Space 1 / KW;
- 55.789451, 37.568336 — Multispace / SOK;
- 55.74963, 37.53743 — Apollax / F2 / SOK / Workki;
- 55.728626, 37.6448 — Space / другая площадка;
- 55.760206, 37.663889 — две площадки в одном адресном кластере.

Правило единого классификатора: операторская площадка (`flex_site`) и проект/здание — разные сущности. Совпадение координаты означает общий адресный кластер, но не слияние строк. Для карты допустимо показывать общий кластер с несколькими операторами.
